SCSS变量

SCSS变量是存储可重复使用值的方式，使用$符号定义。变量可以存储颜色、字符串、数字、布尔值等。

基本语法

$variable-name: value;

实例演示

颜色变量

// 定义颜色变量
$primary-color: #3498db;
$secondary-color: #2ecc71;
$danger-color: #e74c3c;

// 使用变量
.button {
  background-color: $primary-color;
  border: 2px solid $secondary-color;
  
  &:hover {
    background-color: $danger-color;
  }
}

数值变量

// 定义尺寸变量
$base-font-size: 16px;
$header-height: 60px;
$border-radius: 4px;

.header {
  height: $header-height;
  font-size: $base-font-size * 1.2;
  border-radius: $border-radius;
}

字符串变量

// 定义字体变量
$font-family: 'Helvetica Neue', Arial, sans-serif;
$image-path: '/assets/images/';

.content {
  font-family: $font-family;
  background-image: url($image-path + 'bg.jpg');
}

变量作用域

$global-color: #333; // 全局变量

.component {
  $local-color: #666; // 局部变量
  color: $local-color;
  
  .nested {
    color: $global-color; // 可以访问全局变量
    // color: $local-color; // 也可以访问父级局部变量
  }
}

!default 标志

$base-color: #333 !default; // 如果变量未定义则使用此值

// 如果之前已定义 $base-color，则不会被覆盖
$base-color: #666;
$base-color: #999 !default; // 这行不会生效
