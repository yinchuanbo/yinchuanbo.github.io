导入和分片

SCSS | 2025.07.30

SCSS 的 @import 功能允许将样式分割成多个文件，提高代码的可维护性和组织性。

基本导入语法

@import "filename";
@import "path/to/filename";
@import "filename.scss"; // .scss扩展名可选

分片文件（Partials）

分片文件以下划线开头命名，如_variables.scss，这些文件不会被单独编译成 CSS 文件。

实例演示

文件结构

styles/
├── main.scss
├── _variables.scss
├── _mixins.scss
├── _base.scss
└── components/
    ├── _buttons.scss
    └── _navigation.scss

_variables.scss

// 颜色变量
$primary-color: #007bff;
$secondary-color: #6c757d;
$success-color: #28a745;
$danger-color: #dc3545;

// 尺寸变量
$base-font-size: 16px;
$line-height: 1.5;
$border-radius: 4px;

// 断点变量
$mobile: 768px;
$tablet: 1024px;
$desktop: 1200px;

_mixins.scss

// 按钮混合器
@mixin button-style($bg-color, $text-color: white) {
  background-color: $bg-color;
  color: $text-color;
  padding: 0.5rem 1rem;
  border: none;
  border-radius: $border-radius;
  cursor: pointer;

  &:hover {
    background-color: darken($bg-color, 10%);
  }
}

// 响应式混合器
@mixin respond-to($breakpoint) {
  @if $breakpoint == mobile {
    @media (max-width: $mobile) {
      @content;
    }
  }
  @if $breakpoint == tablet {
    @media (max-width: $tablet) {
      @content;
    }
  }
  @if $breakpoint == desktop {
    @media (min-width: $desktop) {
      @content;
    }
  }
}

main.scss（主文件）

// 导入变量和混合器（顺序很重要）
@import "variables";
@import "mixins";

// 导入基础样式
@import "base";

// 导入组件样式
@import "components/buttons";
@import "components/navigation";

// 主要样式
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 1rem;

  @include respond-to(mobile) {
    padding: 0 0.5rem;
  }
}

.main-content {
  padding: 2rem 0;

  @include respond-to(mobile) {
    padding: 1rem 0;
  }
}

导入规则和最佳实践

1. 导入顺序

// 1. 第三方库
@import "normalize";

// 2. 变量和配置
@import "variables";
@import "config";

// 3. 混合器和函数
@import "mixins";
@import "functions";

// 4. 基础样式
@import "base";
@import "typography";

// 5. 布局
@import "layout";

// 6. 组件
@import "components/buttons";
@import "components/forms";

// 7. 页面特定样式
@import "pages/home";
@import "pages/about";

2. 条件导入

$theme: "dark" !default;

@if $theme == "dark" {
  @import "themes/dark";
} @else {
  @import "themes/light";
}

3. 使用@use（SCSS 新语法）

// 推荐使用@use替代@import
@use "variables" as vars;
@use "mixins" as mix;

.button {
  background-color: vars.$primary-color;
  @include mix.button-style(vars.$secondary-color);
}
