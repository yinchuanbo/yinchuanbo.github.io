嵌套规则

SCSS | 2025.07.30

SCSS允许将CSS规则嵌套在其他规则内部，这样可以更清晰地表达HTML结构的层次关系。

基本嵌套

实例演示

// SCSS代码
.navbar {
  background-color: #333;
  padding: 1rem;
  
  ul {
    list-style: none;
    margin: 0;
    padding: 0;
    
    li {
      display: inline-block;
      margin-right: 1rem;
      
      a {
        color: white;
        text-decoration: none;
        padding: 0.5rem;
        
        &:hover {
          background-color: #555;
        }
      }
    }
  }
}

编译后的CSS：

.navbar {
  background-color: #333;
  padding: 1rem;
}

.navbar ul {
  list-style: none;
  margin: 0;
  padding: 0;
}

.navbar ul li {
  display: inline-block;
  margin-right: 1rem;
}

.navbar ul li a {
  color: white;
  text-decoration: none;
  padding: 0.5rem;
}

.navbar ul li a:hover {
  background-color: #555;
}

父选择器引用 (&)

&符号代表父选择器，常用于伪类、伪元素和修饰符类。

.button {
  background-color: #007bff;
  color: white;
  padding: 0.5rem 1rem;
  border: none;
  border-radius: 4px;
  
  // 伪类
  &:hover {
    background-color: #0056b3;
  }
  
  &:active {
    transform: translateY(1px);
  }
  
  // 修饰符类
  &.large {
    padding: 1rem 2rem;
    font-size: 1.2rem;
  }
  
  &.disabled {
    opacity: 0.5;
    cursor: not-allowed;
  }
  
  // 伪元素
  &::before {
    content: '';
    display: inline-block;
    width: 16px;
    height: 16px;
    margin-right: 0.5rem;
  }
}

属性嵌套

对于有命名空间的CSS属性，可以使用嵌套语法：

.text {
  font: {
    family: 'Helvetica Neue', Arial, sans-serif;
    size: 16px;
    weight: bold;
    style: italic;
  }
  
  margin: {
    top: 1rem;
    bottom: 1rem;
    left: 0;
    right: 0;
  }
  
  border: {
    width: 2px;
    style: solid;
    color: #333;
    radius: 4px;
  }
}

嵌套注意事项

避免过度嵌套

// 不推荐：嵌套层级过深
.page {
  .content {
    .article {
      .header {
        .title {
          .text {
            color: #333; // 6层嵌套，过深
          }
        }
      }
    }
  }
}

// 推荐：保持合理的嵌套层级
.article-header {
  .title {
    color: #333;
  }
}

使用@at-root跳出嵌套

.component {
  color: #333;
  
  @at-root .global-style {
    background: white; // 这会生成 .global-style 而不是 .component .global-style
  }
}
