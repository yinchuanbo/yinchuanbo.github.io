简介与环境搭建

TypeScript | 2025.07.31

TypeScript 是由微软开发的开源编程语言，它是 JavaScript 的超集，为 JavaScript 添加了静态类型定义。

什么是 TypeScript

TypeScript 扩展了 JavaScript，通过添加类型定义来提供更好的开发体验：

  • 静态类型检查：在编译时发现错误
  • 更好的 IDE 支持：智能提示、重构、导航
  • 现代 JavaScript 特性：支持最新的 ECMAScript 特性
  • 渐进式采用：可以逐步将 JavaScript 项目迁移到 TypeScript

TypeScript vs JavaScript

// JavaScript
function greet(name) {
    return "Hello, " + name;
}

// TypeScript
function greet(name: string): string {
    return "Hello, " + name;
}

环境搭建

1. 安装 Node.js

首先确保已安装 Node.js（推荐 LTS 版本）

2. 全局安装 TypeScript

npm install -g typescript

3. 验证安装

tsc --version

4. 创建项目

mkdir my-typescript-project
cd my-typescript-project
npm init -y

5. 本地安装 TypeScript

npm install -D typescript @types/node

配置文件 tsconfig.json

创建 TypeScript 配置文件：

tsc --init

基本的 tsconfig.json 配置：

{
  "compilerOptions": {
    "target": "ES2020",
    "module": "commonjs",
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}

第一个 TypeScript 程序

创建 src/index.ts：

// 定义接口
interface User {
    name: string;
    age: number;
    email?: string; // 可选属性
}

// 创建用户对象
const user: User = {
    name: "张三",
    age: 25,
    email: "zhangsan@example.com"
};

// 函数定义
function displayUser(user: User): void {
    console.log(`姓名: ${user.name}`);
    console.log(`年龄: ${user.age}`);
    if (user.email) {
        console.log(`邮箱: ${user.email}`);
    }
}

// 调用函数
displayUser(user);

编译和运行

编译 TypeScript

tsc

运行编译后的 JavaScript

node dist/index.js

使用 ts-node 直接运行

# 安装 ts-node
npm install -D ts-node

# 直接运行 TypeScript 文件
npx ts-node src/index.ts
