简介与安装

Vite7.0 | 2025.07.31

Vite 7.0 是新一代前端构建工具，提供了极速的开发体验和优化的生产构建。本文将介绍 Vite 7.0 的核心概念和安装方法。

什么是 Vite 7.0

Vite 7.0 是一个现代化的前端构建工具，具有以下特点：

  • 极速的冷启动
  • 即时的热模块替换 (HMR)
  • 真正的按需编译
  • 丰富的功能特性
  • 通用的插件 API

核心优势

1. 开发速度

# 传统构建工具启动时间
webpack: ~30s

# Vite 7.0 启动时间
vite: ~200ms

2. 热更新性能

  • 基于 ESM 的 HMR
  • 更新速度与项目大小无关
  • 保持应用状态

3. 现代化特性

  • 原生 ES 模块支持
  • TypeScript 内置支持
  • CSS 预处理器支持
  • 静态资源处理

安装 Vite 7.0

使用 npm

# 创建新项目
npm create vite@latest my-vite-app

# 选择框架和变体
cd my-vite-app
npm install
npm run dev

使用 yarn

# 创建新项目
yarn create vite my-vite-app

# 安装依赖
cd my-vite-app
yarn
yarn dev

使用 pnpm

# 创建新项目
pnpm create vite my-vite-app

# 安装依赖
cd my-vite-app
pnpm install
pnpm dev

项目模板

支持的框架模板

# Vanilla JavaScript
npm create vite@latest my-app -- --template vanilla

# Vue 3
npm create vite@latest my-app -- --template vue

# React
npm create vite@latest my-app -- --template react

# Preact
npm create vite@latest my-app -- --template preact

# Lit
npm create vite@latest my-app -- --template lit

# Svelte
npm create vite@latest my-app -- --template svelte

TypeScript 变体

# Vue + TypeScript
npm create vite@latest my-app -- --template vue-ts

# React + TypeScript
npm create vite@latest my-app -- --template react-ts

# Svelte + TypeScript
npm create vite@latest my-app -- --template svelte-ts

第一个 Vite 应用

1. 创建项目

npm create vite@latest hello-vite -- --template vanilla
cd hello-vite
npm install

2. 查看 package.json

{
  "name": "hello-vite",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
  "devDependencies": {
    "vite": "^7.0.0"
  }
}

3. 启动开发服务器

npm run dev

4. 访问应用

打开浏览器访问 http://localhost:5173

开发命令

开发模式

# 启动开发服务器
npm run dev

# 指定端口
npm run dev -- --port 3000

# 指定主机
npm run dev -- --host 0.0.0.0

构建生产版本

# 构建项目
npm run build

# 预览构建结果
npm run preview

浏览器支持

Vite 7.0 支持的浏览器：

  • Chrome >=87
  • Firefox >=78
  • Safari >=14
  • Edge >=88
