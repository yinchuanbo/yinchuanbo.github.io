Vite 7.0 开发服务器与热更新

Vite7.0 | 2025.07.31

Vite 7.0 的开发服务器提供了极速的开发体验，支持即时热模块替换 (HMR) 和丰富的开发功能。本文将详细介绍开发服务器的使用和配置。

开发服务器特性

核心优势

  • 极速冷启动 (~200ms)
  • 即时热模块替换
  • 真正的按需编译
  • 丰富的中间件支持
  • 内置代理服务器

启动开发服务器

# 默认启动
npm run dev

# 指定端口
npm run dev -- --port 8080

# 指定主机
npm run dev -- --host 0.0.0.0

# 开启 HTTPS
npm run dev -- --https

# 自动打开浏览器
npm run dev -- --open

服务器配置详解

基本配置

// vite.config.js
export default defineConfig({
  server: {
    // 服务器主机名，如果允许外部访问，可设置为 "0.0.0.0"
    host: 'localhost',
    
    // 服务器端口号
    port: 3000,
    
    // 设为 true 时若端口已被占用则会直接退出
    strictPort: false,
    
    // 服务器启动时自动在浏览器中打开应用程序
    open: true,
    
    // 为开发服务器配置 CORS
    cors: true
  }
})

代理配置

export default defineConfig({
  server: {
    proxy: {

热模块替换 (HMR)

HMR 基础概念

热模块替换允许在运行时更新各种模块，而无需完全刷新页面：

// main.js
if (import.meta.hot) {
  // HMR 代码
  import.meta.hot.accept('./App.vue', (newModule) => {
    // 处理更新后的模块
  })
}

HMR API

// 接受自身更新
if (import.meta.hot) {
  import.meta.hot.accept((newModule) => {
    // 更新逻辑
  })
}

// 接受依赖更新
if (import.meta.hot) {
  import.meta.hot.accept('./dependency.js', (newDep) => {
    // 更新依赖
  })
}

// 处理更新失败
if (import.meta.hot) {
  import.meta.hot.accept('./App.vue', (newModule) => {
    if (!newModule) {
      // 更新失败，需要完整重载
      import.meta.hot.invalidate()
    }
  })
}

自定义 HMR 更新逻辑

// counter.js
let count = 0

export function getCount() {
  return count
}

export function increment() {
  count++
}

// HMR 处理
if (import.meta.hot) {
  import.meta.hot.accept((newModule) => {
    // 保持状态
    if (newModule) {
      newModule.count = count
    }
  })
  
  // 数据保存
  import.meta.hot.dispose((data) => {
    data.count = count
  })
  
  // 数据恢复
  if (import.meta.hot.data) {
    count = import.meta.hot.data.count
  }
}

开发中间件

自定义中间件

// vite.config.js
export default defineConfig({
  server: {
    middlewareMode: false,
    
    // 配置中间件
    configureServer(server) {
      server.middlewares.use('/api/test', (req, res, next) => {
        if (req.url === '/api/test') {
          res.end('Hello from custom middleware!')
        } else {
          next()
        }
      })
    }
  }
})

Express 集成

// server.js
import express from 'express'
import { createServer as createViteServer } from 'vite'

async function createServer() {
  const app = express()
  
  // 创建 Vite 服务器
  const vite = await createViteServer({
    server: { middlewareMode: true },
    appType: 'custom'
  })
  
  // 使用 vite 的 Connect 实例作为中间件
  app.use(vite.ssrFixStacktrace)
  app.use(vite.middlewares)
  
  app.listen(3000)
}
