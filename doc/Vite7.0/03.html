开发服务器与热更新

Vite7.0 | 2025.07.31

Vite 的开发服务器是其核心优势之一，提供了极速的启动和热更新体验。本章将深入探讨开发服务器的工作原理和配置选项。

开发服务器原理

ESM 原生支持

Vite 开发服务器直接利用浏览器对 ES 模块的原生支持：

// 浏览器直接请求和执行
import { createApp } from '/node_modules/.vite/deps/vue.js?v=abc123'
import App from '/src/App.vue?t=1234567890'

createApp(App).mount('#app')

按需编译

只有被请求的模块才会被编译，大大提升了启动速度：

// 只有当浏览器请求时才编译
// GET /src/components/Header.vue
// GET /src/utils/helpers.js

HMR 工作原理

// Vite 自动注入 HMR 客户端代码
if (import.meta.hot) {
  // 建立 WebSocket 连接
  const socket = new WebSocket('ws://localhost:5173')
  
  // 监听更新消息
  socket.addEventListener('message', (event) => {
    const { type, updates } = JSON.parse(event.data)
    if (type === 'update') {
      handleUpdate(updates)
    }
  })
}

自定义 HMR API

// src/store.js
let state = { count: 0 }

export const getState = () => state
export const setState = (newState) => {
  state = { ...state, ...newState }
}

// HMR 处理
if (import.meta.hot) {
  // 接受自身更新
  import.meta.hot.accept((newModule) => {
    console.log('Store updated')
  })
  
  // 处理依赖更新
  import.meta.hot.accept('./utils.js', (newModule) => {
    // 重新初始化依赖
  })
  
  // 模块销毁时清理
  import.meta.hot.dispose((data) => {
    // 保存状态
    data.state = state
  })
  
  // 从之前的状态恢复
  if (import.meta.hot.data) {
    state = import.meta.hot.data.state
  }
}

开发服务器中间件

自定义中间件

// vite.config.js
export default defineConfig({
  plugins: [
    {
      name: 'custom-middleware',
      configureServer(server) {
        server.middlewares.use('/api/mock', (req, res, next) => {
          if (req.url === '/api/mock/users') {
            res.setHeader('Content-Type', 'application/json')
            res.end(JSON.stringify([
              { id: 1, name: 'John Doe' },
              { id: 2, name: 'Jane Smith' }
            ]))
          } else {
            next()
          }
        })
      }
    }
  ]
})

HMR 调试

// 在浏览器控制台中监听 HMR 事件
if (import.meta.hot) {
  import.meta.hot.on('vite:beforeUpdate', (payload) => {
    console.log('About to update:', payload)
  })
  
  import.meta.hot.on('vite:afterUpdate', (payload) => {
    console.log('Updated:', payload)
  })
  
  import.meta.hot.on('vite:error', (payload) => {
    console.error('HMR Error:', payload)
  })
}

故障排除

常见 HMR 问题

// 1. 状态丢失问题
if (import.meta.hot) {
  // 保存状态
  import.meta.hot.dispose((data) => {
    data.myState = getCurrentState()
  })
  
  // 恢复状态
  if (import.meta.hot.data) {
    restoreState(import.meta.hot.data.myState)
  }
}

// 2. 循环依赖问题
// 避免在 HMR 边界创建循环依赖

// 3. 副作用清理
if (import.meta.hot) {
  import.meta.hot.dispose(() => {
    // 清理定时器、事件监听器等
    clearInterval(timer)
    element.removeEventListener('click', handler)
  })
}

总结

Vite 的开发服务器通过以下特性提供了卓越的开发体验：

  • 基于 ESM 的即时启动
  • 精确的热模块替换
  • 灵活的代理和中间件配置
  • 强大的调试和监控能力

掌握这些特性将大大提升你的开发效率和体验。
