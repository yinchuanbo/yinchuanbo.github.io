CSS 属性：outline

CSS | 2025.07.15

CSS 的 outline 属性是在一条声明中设置多个轮廓属性的简写属性 ，例如 outline-style, outline-width 和 outline-color。

  • outline: solid;
  • outline: dashed red;
  • outline: 1rem solid;
  • outline: thick double #32a1ce;
  • outline: 8px ridge rgba(170, 50, 220, 0.6);border-radius: 2rem;

border 和 outline

border 和 outline 很类似，但有如下区别：

  1. outline 不占据空间，绘制于元素内容周围。
  2. 根据规范，outline 通常是矩形，但也可以是非矩形的。

语法

/* 样式 */
outline: solid;

/* 样式 | 颜色 */
outline: dashed #f66;

/* 宽度 | 样式 */
outline: thick inset;

/* 宽度 | 样式 | 颜色 */
outline: 3px solid green;

/* 全局值 */
outline: inherit;
outline: initial;
outline: revert;
outline: revert-layer;
outline: unset;

取值

  1. outline-color: 设置轮廓的颜色，没有设置时默认值为 currentcolor。
  2. outline-style: 设置轮廓的样式。没有设置时默认值为 none。
  3. outline-width: 设置轮廓的宽度。没有设置时默认值为 medium。

outline-offset

outline-offset CSS 属性设置轮廓与元素边缘或边框之间的间距。

  • outline-offset: 4px;
  • outline-offset: 0.6rem;
  • outline-offset: 12px;outline: 5px dashed blue;

outline-style

outline-style CSS 属性被用于设置一个元素轮廓的样式。元素轮廓是绘制于元素周围的一条线，位于 border 的外围，使元素突出

语法

/* 关键字 值 */
outline-style: auto;
outline-style: none;
outline-style: dotted;
outline-style: dashed;
outline-style: solid;
outline-style: double;
outline-style: groove;
outline-style: ridge;
outline-style: inset;
outline-style: outset;

/* 全局 值*/
outline-style: inherit;
outline-style: initial;
outline-style: unset;
  • outline-width: 12px;
  • outline-width: thin;
  • outline-width: medium;
  • outline-width: thick;
