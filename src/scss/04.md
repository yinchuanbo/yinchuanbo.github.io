SCSS的@import功能允许将样式分割成多个文件，提高代码的可维护性和组织性。

## 基本导入语法

```scss
@import 'filename';
@import 'path/to/filename';
@import 'filename.scss'; // .scss扩展名可选
```

## 分片文件（Partials）

分片文件以下划线开头命名，如`_variables.scss`，这些文件不会被单独编译成CSS文件。

### 实例演示

#### 文件结构
```
styles/
├── main.scss
├── _variables.scss
├── _mixins.scss
├── _base.scss
└── components/
    ├── _buttons.scss
    └── _navigation.scss
```

#### _variables.scss
```scss
// 颜色变量
$primary-color: #007bff;
$secondary-color: #6c757d;
$success-color: #28a745;
$danger-color: #dc3545;

// 尺寸变量
$base-font-size: 16px;
$line-height: 1.5;
$border-radius: 4px;

// 断点变量
$mobile: 768px;
$tablet: 1024px;
$desktop: 1200px;
```

#### _mixins.scss
```scss
// 按钮混合器
@mixin button-style($bg-color, $text-color: white) {
  background-color: $bg-color;
  color: $text-color;
  padding: 0.5rem 1rem;
  border: none;
  border-radius: $border-radius;
  cursor: pointer;
  
  &:hover {
    background-color: darken($bg-color, 10%);
  }
}

// 响应式混合器
@mixin respond-to($breakpoint) {
  @if $breakpoint == mobile {
    @media (max-width: $mobile) { @content; }
  }
  @if $breakpoint == tablet {
    @media (max-width: $tablet) { @content; }
  }
  @if $breakpoint == desktop {
    @media (min-width: $desktop) { @content; }
  }
}
```

#### _base.scss
```scss
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  font-family: 'Helvetica Neue', Arial, sans-serif;
  font-size: $base-font-size;
  line-height: $line-height;
  color: #333;
}

h1, h2, h3, h4, h5, h6 {
  margin-bottom: 1rem;
  font-weight: 600;
}

p {
  margin-bottom: 1rem;
}
```

#### components/_buttons.scss
```scss
.btn {
  @include button-style($primary-color);
  
  &.btn-secondary {
    @include button-style($secondary-color);
  }
  
  &.btn-success {
    @include button-style($success-color);
  }
  
  &.btn-danger {
    @include button-style($danger-color);
  }
  
  &.btn-large {
    padding: 1rem 2rem;
    font-size: 1.2rem;
  }
  
  &.btn-small {
    padding: 0.25rem 0.5rem;
    font-size: 0.875rem;
  }
}
```

#### components/_navigation.scss
```scss
.navbar {
  background-color: $primary-color;
  padding: 1rem;
  
  .nav-brand {
    color: white;
    font-size: 1.5rem;
    font-weight: bold;
    text-decoration: none;
  }
  
  .nav-menu {
    list-style: none;
    display: flex;
    gap: 1rem;
    
    .nav-item {
      .nav-link {
        color: white;
        text-decoration: none;
        padding: 0.5rem;
        border-radius: $border-radius;
        
        &:hover {
          background-color: rgba(white, 0.1);
        }
        
        &.active {
          background-color: rgba(white, 0.2);
        }
      }
    }
  }
  
  @include respond-to(mobile) {
    .nav-menu {
      flex-direction: column;
      gap: 0.5rem;
    }
  }
}
```

#### main.scss（主文件）
```scss
// 导入变量和混合器（顺序很重要）
@import 'variables';
@import 'mixins';

// 导入基础样式
@import 'base';

// 导入组件样式
@import 'components/buttons';
@import 'components/navigation';

// 主要样式
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 1rem;
  
  @include respond-to(mobile) {
    padding: 0 0.5rem;
  }
}

.main-content {
  padding: 2rem 0;
  
  @include respond-to(mobile) {
    padding: 1rem 0;
  }
}
```

## 导入规则和最佳实践

### 1. 导入顺序
```scss
// 1. 第三方库
@import 'normalize';

// 2. 变量和配置
@import 'variables';
@import 'config';

// 3. 混合器和函数
@import 'mixins';
@import 'functions';

// 4. 基础样式
@import 'base';
@import 'typography';

// 5. 布局
@import 'layout';

// 6. 组件
@import 'components/buttons';
@import 'components/forms';

// 7. 页面特定样式
@import 'pages/home';
@import 'pages/about';
```

### 2. 条件导入
```scss
$theme: 'dark' !default;

@if $theme == 'dark' {
  @import 'themes/dark';
} @else {
  @import 'themes/light';
}
```

### 3. 使用@use（SCSS新语法）
```scss
// 推荐使用@use替代@import
@use 'variables' as vars;
@use 'mixins' as mix;

.button {
  background-color: vars.$primary-color;
  @include mix.button-style(vars.$secondary-color);
}
```
