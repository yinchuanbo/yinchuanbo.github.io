SCSS提供了丰富的内置函数，同时也支持自定义函数，让样式计算更加强大和灵活。

## 自定义函数

### 基本语法

```scss
@function function-name($parameter1, $parameter2: default-value) {
  // 函数逻辑
  @return value;
}
```

### 实例演示

```scss
// 计算rem值的函数
@function rem($pixels, $base: 16px) {
  @return ($pixels / $base) * 1rem;
}

.title {
  font-size: rem(24px); // 1.5rem
  margin-bottom: rem(16px); // 1rem
}

// 计算百分比宽度
@function percentage-width($target, $container) {
  @return ($target / $container) * 100%;
}

.sidebar {
  width: percentage-width(300px, 1200px); // 25%
}

.content {
  width: percentage-width(900px, 1200px); // 75%
}

// 计算网格列宽
@function grid-width($columns, $total-columns: 12, $gutter: 2%) {
  $width: (100% - ($gutter * ($total-columns - 1))) / $total-columns;
  @return $width * $columns + ($gutter * ($columns - 1));
}

.col-4 {
  width: grid-width(4); // 计算4列的宽度
}
```

## 颜色函数

### 颜色调整函数

```scss
$primary-color: #007bff;

.button {
  background-color: $primary-color;
  
  // 调亮颜色
  &.light {
    background-color: lighten($primary-color, 20%);
  }
  
  // 调暗颜色
  &.dark {
    background-color: darken($primary-color, 20%);
  }
  
  // 调整饱和度
  &.saturated {
    background-color: saturate($primary-color, 30%);
  }
  
  &.desaturated {
    background-color: desaturate($primary-color, 30%);
  }
  
  // 调整透明度
  &.transparent {
    background-color: rgba($primary-color, 0.7);
    // 或者使用
    background-color: transparentize($primary-color, 0.3);
  }
  
  // 调整色相
  &.shifted {
    background-color: adjust-hue($primary-color, 60deg);
  }
}
```

### 颜色混合函数

```scss
$color1: #ff0000; // 红色
$color2: #0000ff; // 蓝色

.mixed-colors {
  // 混合颜色
  background-color: mix($color1, $color2); // 紫色
  
  // 指定混合比例
  border-color: mix($color1, $color2, 75%); // 更偏向红色
  
  // 获取颜色的补色
  color: complement($color1);
  
  // 反转颜色
  box-shadow: 0 2px 4px invert($color1);
}
```

### 颜色信息函数

```scss
$test-color: #3498db;

.color-info {
  // 获取颜色通道值
  --red: red($test-color);     // 52
  --green: green($test-color); // 152
  --blue: blue($test-color);   // 219
  --alpha: alpha($test-color); // 1
  
  // 获取HSL值
  --hue: hue($test-color);        // 204deg
  --saturation: saturation($test-color); // 70%
  --lightness: lightness($test-color);   // 53%
  
  // 根据亮度选择文字颜色
  color: if(lightness($test-color) > 50%, #333, white);
}
```

## 数学函数

```scss
// 数学计算函数
@function power($base, $exponent) {
  $result: 1;
  @for $i from 1 through $exponent {
    $result: $result * $base;
  }
  @return $result;
}

// 计算黄金比例
@function golden-ratio($value, $increment: true) {
  @if $increment {
    @return $value * 1.618;
  } @else {
    @return $value / 1.618;
  }
}

// 使用数学函数
.typography {
  $base-size: 1rem;
  
  font-size: $base-size;
  line-height: golden-ratio($base-size);
  
  h1 { font-size: power($base-size, 2); } // 1rem²
  h2 { font-size: golden-ratio($base-size); } // 1.618rem
  h3 { font-size: golden-ratio($base-size, false); } // 0.618rem
}

// 内置数学函数
.math-examples {
  width: percentage(5/8);        // 62.5%
  height: round(3.7px);          // 4px
  margin: ceil(3.2px);           // 4px
  padding: floor(3.8px);         // 3px
  border-width: abs(-2px);       // 2px
  
  // 最大值和最小值
  font-size: max(1rem, 16px);
  line-height: min(1.5, 24px);
}
```

## 字符串函数

```scss
// 字符串处理函数
@function str-replace($string, $search, $replace: '') {
  $index: str-index($string, $search);
  
  @if $index {
    @return str-slice($string, 1, $index - 1) + $replace + 
            str-replace(str-slice($string, $index + str-length($search)), $search, $replace);
  }
  
  @return $string;
}

// 转换为kebab-case
@function to-kebab-case($string) {
  $string: str-replace($string, ' ', '-');
  @return to-lower-case($string);
}

// 使用字符串函数
$component-name: 'Button Primary';
$class-name: to-kebab-case($component-name); // 'button-primary'

.#{$class-name} {
  background-color: #007bff;
}

// 生成BEM类名
@function bem($block, $element: null, $modifier: null) {
  $class: $block;
  
  @if $element {
    $class: $class + '__' + $element;
  }
  
  @if $modifier {
    $class: $class + '--' + $modifier;
  }
  
  @return $class;
}

// 使用BEM函数
.#{bem('card')} {
  background: white;
  
  .#{bem('card', 'header')} {
    padding: 1rem;
    border-bottom: 1px solid #eee;
  }
  
  .#{bem('card', 'body')} {
    padding: 1rem;
  }
  
  &.#{bem('card', null, 'large')} {
    padding: 2rem;
  }
}
```

## 列表和Map函数

```scss
// 列表函数
$colors: #ff0000, #00ff00, #0000ff, #ffff00;

.list-functions {
  // 获取列表长度
  --length: length($colors); // 4
  
  // 获取指定位置的值
  color: nth($colors, 2); // #00ff00
  
  // 获取值的索引
  --index: index($colors, #0000ff); // 3
  
  // 添加值到列表
  $new-colors: append($colors, #ff00ff);
  
  // 合并列表
  $more-colors: #000000, #ffffff;
  $all-colors: join($colors, $more-colors);
}

// Map函数
$theme-config: (
  primary: #007bff,
  secondary: #6c757d,
  font-size: 16px,
  line-height: 1.5
);

.map-functions {
  // 获取Map值
  color: map-get($theme-config, primary);
  font-size: map-get($theme-config, font-size);
  
  // 检查键是否存在
  @if map-has-key($theme-config, border-radius) {
    border-radius: map-get($theme-config, border-radius);
  } @else {
    border-radius: 4px; // 默认值
  }
  
  // 获取所有键
  $keys: map-keys($theme-config); // (primary, secondary, font-size, line-height)
  
  // 获取所有值
  $values: map-values($theme-config);
}

// 深度获取Map值的函数
@function map-deep-get($map, $keys...) {
  @each $key in $keys {
    $map: map-get($map, $key);
  }
  @return $map;
}

$config: (
  theme: (
    colors: (
      primary: #007bff,
      secondary: #6c757d
    ),
    typography: (
      base-size: 16px,
      scale: 1.25
    )
  )
);

.deep-map {
  color: map-deep-get($config, theme, colors, primary);
  font-size: map-deep-get($config, theme, typography, base-size);
}
```

## 实用工具函数

```scss
// 单位转换函数
@function strip-unit($number) {
  @if type-of($number) == 'number' and not unitless($number) {
    @return $number / ($number * 0 + 1);
  }
  @return $number;
}

@function px-to-rem($px, $base: 16px) {
  @return (strip-unit($px) / strip-unit($base)) * 1rem;
}

@function px-to-em($px, $base: 16px) {
  @return (strip-unit($px) / strip-unit($base)) * 1em;
}

// 响应式字体大小函数
@function fluid-font-size($min-size, $max-size, $min-width: 320px, $max-width: 1200px) {
  $slope: ($max-size - $min-size) / ($max-width - $min-width);
  $intersection: (-$min-width * $slope) + $min-size;
  
  @return clamp(#{$min-size}, #{$intersection} + #{$slope * 100vw}, #{$max-size});
}

// 颜色对比度函数
@function contrast-ratio($color1, $color2) {
  $l1: lightness($color1);
  $l2: lightness($color2);
  
  @if $l1 > $l2 {
    @return ($l1 + 5) / ($l2 + 5);
  } @else {
    @return ($l2 + 5) / ($l1 + 5);
  }
}

@function accessible-color($background, $light: white, $dark: black) {
  $light-contrast: contrast-ratio($background, $light);
  $dark-contrast: contrast-ratio($background, $dark);
  
  @return if($light-contrast > $dark-contrast, $light, $dark);
}

// 使用工具函数
.responsive-text {
  font-size: fluid-font-size(1rem, 2rem);
  color: accessible-color(#007bff); // 自动选择对比度最好的颜色
}

.converted-sizes {
  width: px-to-rem(320px);    // 20rem
  height: px-to-em(240px);    // 15em
  margin: strip-unit(1.5rem); // 1.5
}
```

## 高级函数应用

```scss
// 生成调色板的函数
@function generate-palette($base-color, $steps: 5) {
  $palette: ();
  
  @for $i from 1 through $steps {
    $lightness: 90% - (($i - 1) * 20%);
    $color: hsl(hue($base-color), saturation($base-color), $lightness);
    $palette: map-merge($palette, (#{$i * 100}: $color));
  }
  
  @return $palette;
}

// 使用调色板函数
$blue-palette: generate-palette(#007bff);

.palette-demo {
  @each $weight, $color in $blue-palette {
    .bg-blue-#{$weight} {
      background-color: $color;
    }
  }
}

// 动态主题生成函数
@function create-theme($primary, $secondary: null, $accent: null) {
  @if not $secondary {
    $secondary: adjust-hue($primary, 180deg);
  }
  
  @if not $accent {
    $accent: adjust-hue($primary, 60deg);
  }
  
  @return (
    primary: $primary,
    primary-light: lighten($primary, 20%),
    primary-dark: darken($primary, 20%),
    secondary: $secondary,
    secondary-light: lighten($secondary, 20%),
    secondary-dark: darken($secondary, 20%),
    accent: $accent,
    text-on-primary: accessible-color($primary),
    text-on-secondary: accessible-color($secondary),
    text-on-accent: accessible-color($accent)
  );
}

$my-theme: create-theme(#e91e63);

.themed-component {
  background-color: map-get($my-theme, primary);
  color: map-get($my-theme, text-on-primary);
  
  .accent {
    background-color: map-get($my-theme, accent);
    color: map-get($my-theme, text-on-accent);
  }
}
```
