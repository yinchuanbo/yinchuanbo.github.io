SCSS的新模块系统使用@use和@forward替代@import，提供更好的命名空间管理和依赖控制。

## @use基本语法

```scss
@use 'path/to/module';
@use 'path/to/module' as alias;
@use 'path/to/module' as *; // 全局导入
@use 'path/to/module' with ($variable: value);
```

## 实例演示

### 基本模块使用

#### _colors.scss
```scss
// 颜色变量
$primary: #007bff !default;
$secondary: #6c757d !default;
$success: #28a745 !default;
$danger: #dc3545 !default;

// 颜色函数
@function get-color($name) {
  $colors: (
    primary: $primary,
    secondary: $secondary,
    success: $success,
    danger: $danger
  );
  @return map-get($colors, $name);
}

// 颜色混合器
@mixin color-variant($color, $background: false) {
  @if $background {
    background-color: $color;
    color: if(lightness($color) > 50%, #333, white);
  } @else {
    color: $color;
  }
}
```

#### _typography.scss
```scss
// 字体变量
$font-family-base: 'Helvetica Neue', Arial, sans-serif !default;
$font-size-base: 1rem !default;
$line-height-base: 1.5 !default;

// 字体大小映射
$font-sizes: (
  xs: 0.75rem,
  sm: 0.875rem,
  base: 1rem,
  lg: 1.125rem,
  xl: 1.25rem,
  2xl: 1.5rem,
  3xl: 1.875rem,
  4xl: 2.25rem
) !default;

// 字体混合器
@mixin font-size($size) {
  @if map-has-key($font-sizes, $size) {
    font-size: map-get($font-sizes, $size);
  } @else {
    font-size: $size;
  }
}

@mixin heading($level: 1) {
  font-weight: 600;
  line-height: 1.2;
  margin-bottom: 0.5rem;
  
  @if $level == 1 {
    @include font-size(3xl);
  } @else if $level == 2 {
    @include font-size(2xl);
  } @else if $level == 3 {
    @include font-size(xl);
  } @else {
    @include font-size(lg);
  }
}
```

#### main.scss（使用模块）
```scss
// 使用命名空间导入
@use 'colors';
@use 'typography' as typo;

// 使用模块中的变量和函数
.button {
  background-color: colors.get-color(primary);
  @include colors.color-variant(colors.$primary, true);
  @include typo.font-size(base);
  
  &:hover {
    background-color: darken(colors.$primary, 10%);
  }
}

.heading {
  @include typo.heading(1);
  color: colors.$secondary;
}
```

### 配置模块变量

#### _config.scss
```scss
// 默认配置
$enable-rounded: true !default;
$enable-shadows: true !default;
$enable-gradients: false !default;
$enable-transitions: true !default;

$border-radius: 0.375rem !default;
$border-radius-sm: 0.25rem !default;
$border-radius-lg: 0.5rem !default;

$box-shadow: 0 0.125rem 0.25rem rgba(0, 0, 0, 0.075) !default;
$box-shadow-sm: 0 0.125rem 0.25rem rgba(0, 0, 0, 0.075) !default;
$box-shadow-lg: 0 1rem 3rem rgba(0, 0, 0, 0.175) !default;
```

#### _components.scss
```scss
@use 'config';

@mixin card($shadow: true, $rounded: true) {
  background-color: white;
  padding: 1rem;
  
  @if $rounded and config.$enable-rounded {
    border-radius: config.$border-radius;
  }
  
  @if $shadow and config.$enable-shadows {
    box-shadow: config.$box-shadow;
  }
}

@mixin button($variant: primary) {
  padding: 0.5rem 1rem;
  border: none;
  cursor: pointer;
  
  @if config.$enable-rounded {
    border-radius: config.$border-radius-sm;
  }
  
  @if config.$enable-transitions {
    transition: all 0.15s ease-in-out;
  }
}
```

#### app.scss（配置并使用）
```scss
// 配置模块变量
@use 'components' with (
  $enable-rounded: false,
  $enable-shadows: true,
  $border-radius: 8px
);

.my-card {
  @include components.card;
}

.my-button {
  @include components.button;
}
```

## @forward转发模块

### 创建统一入口

#### _index.scss（转发多个模块）
```scss
// 转发所有模块
@forward 'colors';
@forward 'typography';
@forward 'components';

// 转发时添加前缀
@forward 'utilities' as util-*;

// 转发时隐藏某些成员
@forward 'internal' hide $private-var, private-mixin;

// 转发时只显示某些成员
@forward 'helpers' show get-spacing, spacing-mixin;
```

#### 使用统一入口
```scss
@use 'index' as *; // 导入所有转发的模块

.component {
  color: $primary; // 来自colors模块
  @include heading(2); // 来自typography模块
  @include card; // 来自components模块
}
```

### 模块重新导出

    @content;

## 高级模块模式

### 插件系统

#### _plugin-base.scss
```scss
// 插件基础接口
@mixin plugin-init($config: ()) {
  @error "plugin-init mixin must be implemented";
}

@function plugin-get($key) {
  @error "plugin-get function must be implemented";
}
```

#### _animation-plugin.scss
```scss
@use 'plugin-base';

// 动画插件配置
$config: () !default;
$default-config: (
  duration: 0.3s,
  timing: ease,
  delay: 0s
);

@mixin plugin-init($user-config: ()) {
  $config: map-merge($default-config, $user-config) !global;
}

@function plugin-get($key) {
  @return map-get($config, $key);
}

// 动画混合器
@mixin animate($name, $duration: null, $timing: null) {
  $duration: if($duration, $duration, plugin-get(duration));
  $timing: if($timing, $timing, plugin-get(timing));
  
  animation: #{$name} #{$duration} #{$timing};
}

@mixin fade-in($duration: null) {
  @include animate(fadeIn, $duration);
  
  @keyframes fadeIn {
    from { opacity: 0; }
    to { opacity: 1; }
  }
}
```

#### 使用插件
```scss
@use 'animation-plugin' with (
  $config: (
    duration: 0.5s,
    timing: ease-out
  )
);

.modal {
  @include animation-plugin.fade-in;
}
```

### 条件模块加载

#### _responsive.scss
```scss
$breakpoints: (
  sm: 576px,
  md: 768px,
  lg: 992px,
  xl: 1200px
) !default;

$enable-responsive: true !default;

@mixin respond-above($breakpoint) {
  @if $enable-responsive {
    $size: map-get($breakpoints, $breakpoint);
    @if $size {
      @media (min-width: #{$size}) {
        @content;
      }
    }
  } @else {
    @content;
  }
}
```

### 模块版本控制

#### _version.scss
```scss
$version: '2.1.0' !default;
$api-version: 2 !default;

@function check-version($required-version) {
  // 简单的版本检查逻辑
  @return $version == $required-version;
}

@function check-api-version($required-api) {
  @return $api-version >= $required-api;
}

@mixin require-version($version) {
  @if not check-version($version) {
    @error "This code requires version #{$version}, but #{$version} is loaded.";
  }
}

@mixin require-api($api) {
  @if not check-api-version($api) {
    @error "This code requires API version #{$api} or higher.";
  }
}
```

#### 使用版本控制
```scss
@use 'version';

// 检查版本兼容性
@include version.require-api(2);

.new-feature {
  @if version.check-api-version(2) {
    // 使用新API
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  } @else {
    // 降级到旧API
    display: flex;
    flex-wrap: wrap;
  }
}
```

## 最佳实践

### 1. 模块组织结构
```
styles/
├── abstracts/
│   ├── _variables.scss
│   ├── _functions.scss
│   ├── _mixins.scss
│   └── _index.scss
├── base/
│   ├── _reset.scss
│   ├── _typography.scss
│   └── _index.scss
├── components/
│   ├── _buttons.scss
│   ├── _cards.scss
│   └── _index.scss
├── layout/
│   ├── _grid.scss
│   ├── _header.scss
│   └── _index.scss
└── main.scss
```

### 2. 命名约定
```scss
// 使用有意义的命名空间
@use 'abstracts/variables' as vars;
@use 'abstracts/mixins' as mix;
@use 'components/buttons' as btn;

.my-component {
  color: vars.$primary-color;
  @include mix.center-content;
  @include btn.style(primary);
}
```

### 3. 避免循环依赖
```scss
// ❌ 错误：循环依赖
// _a.scss
@use 'b';

// _b.scss  
@use 'a'; // 循环依赖

// ✅ 正确：提取共同依赖
// _shared.scss
$shared-variable: value;

// _a.scss
@use 'shared';

// _b.scss
@use 'shared';
```

### 4. 合理使用@forward
```scss
// 创建主题包
// themes/dark/_index.scss
@forward 'variables';
@forward 'components';
@forward 'utilities';

// 使用主题包
@use 'themes/dark' as *;
```
