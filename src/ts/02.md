TypeScript 提供了丰富的类型系统，帮助开发者在编译时捕获错误并提供更好的代码提示。

## 原始类型

### 布尔类型 (boolean)
```typescript
let isDone: boolean = false;
let isActive: boolean = true;

// 函数返回布尔值
function isEven(num: number): boolean {
    return num % 2 === 0;
}
```

### 数字类型 (number)
```typescript
let decimal: number = 6;
let hex: number = 0xf00d;
let binary: number = 0b1010;
let octal: number = 0o744;
let big: bigint = 100n;
```

### 字符串类型 (string)
```typescript
let color: string = "blue";
let fullName: string = `Bob Bobbington`;
let age: number = 37;
let sentence: string = `Hello, my name is ${fullName}.
I'll be ${age + 1} years old next month.`;
```

### 空值类型 (void)
```typescript
// 函数没有返回值
function warnUser(): void {
    console.log("This is my warning message");
}

// void 类型的变量只能赋值 undefined 或 null
let unusable: void = undefined;
```

### Null 和 Undefined
```typescript
let u: undefined = undefined;
let n: null = null;

// 默认情况下，null 和 undefined 是所有类型的子类型
let num: number = undefined; // 在严格模式下会报错
```

### Never 类型
```typescript
// 返回 never 的函数必须存在无法达到的终点
function error(message: string): never {
    throw new Error(message);
}

// 推断的返回值类型为 never
function fail() {
    return error("Something failed");
}

// 返回 never 的函数必须存在无法达到的终点
function infiniteLoop(): never {
    while (true) {
    }
}
```

## 数组类型

### 数组的两种定义方式
```typescript
// 方式一：类型 + []
let list: number[] = [1, 2, 3];
let names: string[] = ["Alice", "Bob", "Charlie"];

// 方式二：Array<类型>
let list2: Array<number> = [1, 2, 3];
let names2: Array<string> = ["Alice", "Bob", "Charlie"];
```

### 多维数组
```typescript
let matrix: number[][] = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];

let cube: number[][][] = [
    [[1, 2], [3, 4]],
    [[5, 6], [7, 8]]
];
```

## 元组类型 (Tuple)

元组类型允许表示一个已知元素数量和类型的数组：

```typescript
// 声明一个元组类型
let x: [string, number];

// 正确的初始化
x = ["hello", 10];

// 错误的初始化
// x = [10, "hello"]; // Error

// 访问元组元素
console.log(x[0].substring(1)); // OK
console.log(x[1].substring(1)); // Error, 'number' 没有 'substring' 方法
```

### 元组的可选元素和剩余元素
```typescript
// 可选元素
let optionalTuple: [string, number?] = ["hello"];

// 剩余元素
let restTuple: [string, ...number[]] = ["hello", 1, 2, 3, 4];

// 命名元组
let namedTuple: [name: string, age: number] = ["Alice", 25];
```

## 枚举类型 (Enum)

### 数字枚举
```typescript
enum Direction {
    Up,    // 0
    Down,  // 1
    Left,  // 2
    Right  // 3
}

let dir: Direction = Direction.Up;

// 手动设置枚举值
enum Status {
    Pending = 1,
    Approved = 2,
    Rejected = 3
}
```

### 字符串枚举
```typescript
enum Color {
    Red = "red",
    Green = "green",
    Blue = "blue"
}

let favoriteColor: Color = Color.Red;
console.log(favoriteColor); // "red"
```

### 异构枚举
```typescript
enum BooleanLikeHeterogeneousEnum {
    No = 0,
    Yes = "YES",
}
```

### 常量枚举
```typescript
const enum Directions {
    Up,
    Down,
    Left,
    Right
}

let directions = [
    Directions.Up,
    Directions.Down,
    Directions.Left,
    Directions.Right
];
```

## Any 类型

```typescript
let notSure: any = 4;
notSure = "maybe a string instead";
notSure = false; // 也可以是个 boolean

// any 类型可以访问任何属性和方法
let anyValue: any = "hello";
anyValue.foo.bar; // OK
anyValue.trim(); // OK
anyValue(); // OK
new anyValue(); // OK
```

## Unknown 类型

```typescript
let userInput: unknown;
let userName: string;

userInput = 5;
userInput = "Max";

// 不能直接赋值给其他类型
// userName = userInput; // Error

// 需要类型检查
if (typeof userInput === "string") {
    userName = userInput; // OK
}
```

## 类型断言

### 两种语法形式
```typescript
let someValue: unknown = "this is a string";

// 尖括号语法
let strLength: number = (<string>someValue).length;

// as 语法（推荐，在 JSX 中只能使用这种）
let strLength2: number = (someValue as string).length;
```

### 非空断言操作符
```typescript
function processUser(user?: { name: string }) {
    // 使用非空断言操作符
    console.log(user!.name); // 告诉编译器 user 不为 null/undefined
}
```

## 联合类型

```typescript
let id: number | string;
id = 123;     // OK
id = "ABC";   // OK
// id = true; // Error

function printId(id: number | string) {
    if (typeof id === "string") {
        console.log(id.toUpperCase());
    } else {
        console.log(id.toFixed(2));
    }
}
```

## 类型别名

```typescript
type StringOrNumber = string | number;
type User = {
    name: string;
    age: number;
};

let value: StringOrNumber = "hello";
let user: User = { name: "Alice", age: 25 };
```

## 实际应用示例

```typescript
// 用户信息类型定义
type UserRole = "admin" | "user" | "guest";

interface UserProfile {
    id: number;
    username: string;
    email: string;
    role: UserRole;
    isActive: boolean;
    lastLogin?: Date;
    preferences: {
        theme: "light" | "dark";
        language: string;
    };
}

// 创建用户
const createUser = (userData: Omit<UserProfile, "id">): UserProfile => {
    return {
        id: Math.random(),
        ...userData
    };
};

// 使用示例
const newUser = createUser({
    username: "johndoe",
    email: "john@example.com",
    role: "user",
    isActive: true,
    preferences: {
        theme: "dark",
        language: "zh-CN"
    }
});
```
