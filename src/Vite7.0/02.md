本章将指导你快速创建和配置 Vite 7.0 项目，从零开始体验 Vite 的强大功能。

## 环境要求

### 系统要求
- **Node.js 版本**: >= 18.0.0
- **包管理器**: npm、yarn、pnpm 或 bun

```bash
# 检查 Node.js 版本
node --version

# 检查 npm 版本
npm --version
```

## 创建新项目

### 使用 create-vite 脚手架

```bash
# npm
npm create vite@latest my-vite-app

# yarn
yarn create vite my-vite-app

# pnpm
pnpm create vite my-vite-app

# bun
bun create vite my-vite-app
```

### 选择模板

创建项目时，你可以选择不同的模板：

```bash
# 直接指定模板
npm create vite@latest my-vue-app -- --template vue
npm create vite@latest my-react-app -- --template react
npm create vite@latest my-svelte-app -- --template svelte
```

### 可用模板列表

| 模板名称 | 描述 |
|----------|------|
| `vanilla` | 原生 JavaScript |
| `vanilla-ts` | 原生 TypeScript |
| `vue` | Vue 3 |
| `vue-ts` | Vue 3 + TypeScript |
| `react` | React |
| `react-ts` | React + TypeScript |
| `react-swc` | React + SWC |
| `react-swc-ts` | React + SWC + TypeScript |
| `preact` | Preact |
| `preact-ts` | Preact + TypeScript |
| `lit` | Lit |
| `lit-ts` | Lit + TypeScript |
| `svelte` | Svelte |
| `svelte-ts` | Svelte + TypeScript |
| `solid` | SolidJS |
| `solid-ts` | SolidJS + TypeScript |
| `qwik` | Qwik |
| `qwik-ts` | Qwik + TypeScript |

## 项目结构解析

### 基础 Vue 项目结构
```
my-vite-app/
├── public/
│   └── favicon.ico
├── src/
│   ├── assets/
│   │   └── vue.svg
│   ├── components/
│   │   └── HelloWorld.vue
│   ├── App.vue
│   └── main.js
├── index.html
├── package.json
├── vite.config.js
└── README.md
```

### 关键文件说明

#### index.html
```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <link rel="icon" type="image/svg+xml" href="/vite.svg" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Vite + Vue</title>
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.js"></script>
  </body>
</html>
```

#### package.json
```json
{
  "name": "my-vite-app",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "vue": "^3.4.0"
  },
  "devDependencies": {
    "@vitejs/plugin-vue": "^5.0.0",
    "vite": "^7.0.0"
  }
}
```

#### vite.config.js
```javascript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  plugins: [vue()],
})
```

## 启动开发服务器

### 安装依赖并启动
```bash
cd my-vite-app

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 开发服务器特性
- **端口**: 默认 5173，如果被占用会自动递增
- **热更新**: 文件修改后自动刷新
- **错误覆盖**: 运行时错误会在浏览器中显示

```bash
# 自定义端口启动
npm run dev -- --port 3000

# 指定主机
npm run dev -- --host 0.0.0.0
```

## 手动创建项目

### 1. 初始化项目
```bash
mkdir my-manual-vite-app
cd my-manual-vite-app
npm init -y
```

### 2. 安装 Vite
```bash
# 安装 Vite
npm install -D vite

# 安装框架依赖（以 Vue 为例）
npm install vue
npm install -D @vitejs/plugin-vue
```

### 3. 创建基础文件

#### index.html
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Vite App</title>
</head>
<body>
  <div id="app"></div>
  <script type="module" src="/src/main.js"></script>
</body>
</html>
```

#### src/main.js
```javascript
import { createApp } from 'vue'
import App from './App.vue'

createApp(App).mount('#app')
```

#### src/App.vue
```vue
<template>
  <div>
    <h1>Hello Vite!</h1>
    <p>{{ message }}</p>
  </div>
</template>

<script>
export default {
  data() {
    return {
      message: 'Welcome to Vite 7.0!'
    }
  }
}
</script>

<style>
h1 {
  color: #42b883;
}
</style>
```

### 4. 配置脚本
```json

    "build": "vite build",

  }
}
```

## 常用命令

### 开发命令
```bash
# 启动开发服务器
npm run dev

# 指定端口
npm run dev -- --port 8080

# 开放外部访问
npm run dev -- --host

# 强制重新优化依赖
npm run dev -- --force
```

### 构建命令
```bash
# 构建生产版本
npm run build

# 预览构建结果
npm run preview

# 分析构建包大小
npm run build -- --analyze
```

## 故障排除

### 常见问题

#### 1. 端口被占用
```bash
# 查看端口占用
netstat -ano | findstr :5173

# 使用不同端口
npm run dev -- --port 3000
```

#### 2. 模块解析错误
```javascript
// vite.config.js
export default defineConfig({
  resolve: {
    alias: {
      '@': path.resolve(__dirname, 'src')
    }
  }
})
```

#### 3. 依赖预构建问题
```bash
# 清除缓存
rm -rf node_modules/.vite

# 重新安装依赖
npm install
```
