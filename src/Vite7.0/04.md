Vite 7.0 提供了强大的静态资源处理能力，支持多种资源类型的导入、优化和处理。本文将详细介绍静态资源的处理方法和最佳实践。

## 静态资源导入

### 基本资源导入
```javascript
// 导入静态资源会返回解析后的公共 URL
import imgUrl from './img.png'

// 在模板中使用
document.getElementById('hero-img').src = imgUrl
```

### 显式 URL 导入
```javascript
// 显式导入为 URL
import assetAsURL from './asset.js?url'

// 导入为字符串
import assetAsString from './shader.glsl?raw'

// 导入为 Web Worker

// 导入为内联 Web Worker

```

### 动态导入资源
```javascript
// 动态导入

  return new URL(`./dir/${name}.png`, import.meta.url).href
}

// 使用示例
const imgUrl = getImageUrl('hero')
```

## 图片资源处理

### 图片格式支持
```javascript
// 支持的图片格式
import jpegImg from './image.jpg'
import pngImg from './image.png'
import gifImg from './image.gif'
import svgImg from './image.svg'
import webpImg from './image.webp'
import avifImg from './image.avif'
```

### 图片优化配置
```javascript
// vite.config.js
export default defineConfig({
  build: {
    // 小于此阈值的导入或引用资源将内联为 base64 编码
    assetsInlineLimit: 4096,
    
    rollupOptions: {
      output: {
        assetFileNames: (assetInfo) => {
          const info = assetInfo.name.split('.')
          const extType = info[info.length - 1]
          
          if (/\.(png|jpe?g|gif|svg|webp|avif)$/i.test(assetInfo.name)) {
            return `images/[name]-[hash][extname]`
          }
          
          return `assets/[name]-[hash][extname]`
        }
      }
    }
  }
})
```

### 响应式图片
```javascript
// 导入不同尺寸的图片
import heroSmall from './hero-small.jpg'

      <source media="(max-width: 1200px)" srcset="${heroMedium}">
      <img src="${heroLarge}" alt="Hero Image">
    </picture>
  `
}
```

## Web Workers

### Worker 文件创建
```javascript
// worker.js
self.onmessage = function(e) {
  const { data } = e
  
  // 执行计算密集型任务
  const result = heavyComputation(data)
  
  // 发送结果回主线程
  self.postMessage(result)
}

function heavyComputation(data) {
  // 模拟重计算
  let result = 0
  for (let i = 0; i < data.iterations; i++) {
    result += Math.random()
  }
  return result
}
```

### Worker 使用
```javascript
// 导入 Worker
import MyWorker from './worker.js?worker'

// 创建 Worker 实例
const worker = new MyWorker()

// 发送数据到 Worker
worker.postMessage({ iterations: 1000000 })

// 接收 Worker 结果
worker.onmessage = function(e) {
  console.log('Worker result:', e.data)
}

// 内联 Worker
import InlineWorker from './worker.js?worker&inline'
const inlineWorker = new InlineWorker()
```

## 资源优化策略

### 资源压缩
```javascript
// vite.config.js
import { defineConfig } from 'vite'
import { resolve } from 'path'

export default defineConfig({
  build: {
    // 启用 gzip 压缩
    reportCompressedSize: true,
    
    // 资源内联阈值
    assetsInlineLimit: 4096,
    
    rollupOptions: {
      output: {
        // 分离 CSS
        assetFileNames: (assetInfo) => {
          const info = assetInfo.name.split('.')
          const extType = info[info.length - 1]
          
          if (extType === 'css') {
            return 'css/[name]-[hash][extname]'
          }
          
          if (/\.(png|jpe?g|gif|svg|webp|avif)$/i.test(assetInfo.name)) {
            return 'images/[name]-[hash][extname]'
          }
          
          return 'assets/[name]-[hash][extname]'
        }
      }
    }
  }
})
```

### 条件资源加载
```javascript
// 根据设备能力加载资源
const supportsWebP = () => {
  const canvas = document.createElement('canvas')
  return canvas.toDataURL('image/webp').indexOf('webp') > -1
}

const getImageUrl = (name) => {
  const format = supportsWebP() ? 'webp' : 'jpg'
  return new URL(`./images/${name}.${format}`, import.meta.url).href
}
```

```
├── assets/
│   ├── images/
```

### 性能优化建议
1. 使用适当的图片格式 (WebP, AVIF)
2. 启用图片懒加载
3. 合理设置资源内联阈值
4. 使用 CDN 加速静态资源
5. 启用浏览器缓存
