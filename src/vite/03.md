Vite 的开发服务器是其核心优势之一，提供了极速的启动和热更新体验。本章将深入探讨开发服务器的工作原理和配置选项。

## 开发服务器原理

### ESM 原生支持
Vite 开发服务器直接利用浏览器对 ES 模块的原生支持：

```javascript
// 浏览器直接请求和执行
import { createApp } from '/node_modules/.vite/deps/vue.js?v=abc123'
import App from '/src/App.vue?t=1234567890'

createApp(App).mount('#app')
```

### 按需编译
只有被请求的模块才会被编译，大大提升了启动速度：

```javascript
// 只有当浏览器请求时才编译
// GET /src/components/Header.vue
// GET /src/utils/helpers.js
```

## 服务器配置

### 基础配置
```javascript
// vite.config.js
export default defineConfig({
  server: {
    port: 3000,           // 端口号
    host: true,           // 监听所有地址
    open: true,           // 自动打开浏览器
    cors: true,           // 启用 CORS
    strictPort: false,    // 端口被占用时是否退出
  }
})
```

### 高级服务器配置
```javascript
export default defineConfig({
  server: {
    // 自定义中间件
    middlewareMode: false,
    
    // 代理配置
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      },
      '/socket.io': {
        target: 'ws://localhost:8080',
        ws: true
      }
    },
    
    // HTTPS 配置
    https: {
      key: fs.readFileSync('path/to/key.pem'),
      cert: fs.readFileSync('path/to/cert.pem')
    },
    
    // 文件系统访问限制
    fs: {
      strict: true,
      allow: ['..', '/absolute/path'],
      deny: ['.env', '.env.*', '*.{pem,crt}']
    }
  }
})
```

## 热模块替换 (HMR)

### HMR 工作原理
```javascript
// Vite 自动注入 HMR 客户端代码
if (import.meta.hot) {
  // 建立 WebSocket 连接
  const socket = new WebSocket('ws://localhost:5173')
  
  // 监听更新消息
  socket.addEventListener('message', (event) => {
    const { type, updates } = JSON.parse(event.data)
    if (type === 'update') {
      handleUpdate(updates)
    }
  })
}
```

### Vue 组件 HMR
```vue
<!-- src/components/Counter.vue -->
<template>
  <div>
    <p>Count: {{ count }}</p>
    <button @click="increment">+</button>
  </div>
</template>

<script>
export default {
  data() {
    return {
      count: 0
    }
  },
  methods: {
    increment() {
      this.count++
    }
  }
}
</script>

<style scoped>
button {
  background: #42b883;
  color: white;
  border: none;
  padding: 8px 16px;
  border-radius: 4px;
}
</style>
```

### React 组件 HMR
```jsx
// src/components/Counter.jsx
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        +
      </button>
    </div>
  )
}

export default Counter

// HMR 边界自动处理
if (import.meta.hot) {
  import.meta.hot.accept()
}
```

### 自定义 HMR API
```javascript
// src/store.js
let state = { count: 0 }

export const getState = () => state
export const setState = (newState) => {
  state = { ...state, ...newState }
}

// HMR 处理
if (import.meta.hot) {
  // 接受自身更新
  import.meta.hot.accept((newModule) => {
    console.log('Store updated')
  })
  
  // 处理依赖更新
  import.meta.hot.accept('./utils.js', (newModule) => {
    // 重新初始化依赖
  })
  
  // 模块销毁时清理
  import.meta.hot.dispose((data) => {
    // 保存状态
    data.state = state
  })
  
  // 从之前的状态恢复
  if (import.meta.hot.data) {
    state = import.meta.hot.data.state
  }
}
```

## 开发服务器中间件

### 自定义中间件
```javascript
// vite.config.js
export default defineConfig({
  plugins: [
    {
      name: 'custom-middleware',
      configureServer(server) {
        server.middlewares.use('/api/mock', (req, res, next) => {
          if (req.url === '/api/mock/users') {
            res.setHeader('Content-Type', 'application/json')
            res.end(JSON.stringify([
              { id: 1, name: 'John Doe' },
              { id: 2, name: 'Jane Smith' }
            ]))
          } else {
            next()
          }
        })
      }
    }
  ]
})
```

### 代理中间件
```javascript
export default defineConfig({
  server: {
    proxy: {
      // 字符串简写
      '/foo': 'http://localhost:4567',
      
      // 带选项

        target: 'http://jsonplaceholder.typicode.com',
        changeOrigin: true,

      // 正则表达式
      '^/fallback/.*': {
        target: 'http://jsonplaceholder.typicode.com',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/fallback/, '')
      },

      }
    }
  }
})
```

### HMR 调试
```javascript
// 在浏览器控制台中监听 HMR 事件
if (import.meta.hot) {
  import.meta.hot.on('vite:beforeUpdate', (payload) => {
    console.log('About to update:', payload)
  })
  
  import.meta.hot.on('vite:afterUpdate', (payload) => {
    console.log('Updated:', payload)
  })
  
  import.meta.hot.on('vite:error', (payload) => {
    console.error('HMR Error:', payload)
  })
}
```

## 故障排除

### 常见 HMR 问题
```javascript
// 1. 状态丢失问题
if (import.meta.hot) {
  // 保存状态
  import.meta.hot.dispose((data) => {
    data.myState = getCurrentState()
  })
  
  // 恢复状态
  if (import.meta.hot.data) {
    restoreState(import.meta.hot.data.myState)
  }
}

// 2. 循环依赖问题
// 避免在 HMR 边界创建循环依赖

// 3. 副作用清理
if (import.meta.hot) {
  import.meta.hot.dispose(() => {
    // 清理定时器、事件监听器等
    clearInterval(timer)
    element.removeEventListener('click', handler)
  })
}
```
