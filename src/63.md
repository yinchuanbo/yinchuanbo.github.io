[Streams API](https://developer.mozilla.org/en-US/docs/Web/API/Streams_API)让您能够访问通过网络接收的数据流，并在网页上使用 JavaScript 进行处理。以前，如果您想处理通过网络获取的数据，必须下载整个资源，等待其转换为您能够处理的格式，然后才能开始处理。使用 Streams API，您可以在原始数据到达时使用 JavaScript 进行处理，这使得 Streams API 非常适合处理连续数据源、动态转换数据、在收到所需数据后取消流等等。

在本文中，我们将探讨 Streams API 的概念、用法和实际应用。我们还将通过一个实际示例，构建一个使用该 API 转换数据流的小型应用程序。

## 了解 Streams API

Streams API 提供了一种在 JavaScript 中处理流数据的标准方法。它允许您逐块处理数据，从而高效地处理 Web 应用程序中的大型资源或实时数据。您应该了解 Streams API 中的以下关键概念：

**块**

数据以块（称为“块”）的形式按顺序读取。一个块可以是一个字节，也可以是更大的字节，例如特定大小的[类型化数组](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Typed_arrays)。单个流可以包含不同大小和类型的块。

**背压**

该 API 自动管理背压，确保快速生产者不会压垮慢速消费者。这通过内部排队机制实现。

**管道**

API 提供了像[`pipeThrough()`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream/pipeThrough)和这样的方法[`pipeTo()`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream/pipeTo)来连接流，从而允许链式处理数据。

API 包括针对不同类型流的以下抽象：

[ReadableStream](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream)

表示可从中读取数据的源。它可以从各种来源创建，例如获取响应或文件输入。

[WritableStream](https://developer.mozilla.org/en-US/docs/Web/API/WritableStream)

表示可以写入数据的目标位置。它可用于执行写入文件或向服务器发送数据等任务。

[TransformStream](https://developer.mozilla.org/en-US/docs/Web/API/TransformStream)

允许在数据从可读流传递到可写流时对其进行修改。这对于压缩或加密等任务非常有用。

## 创建示例 Streams API 应用

1. 在 streaming-app 目录中，创建一个 JavaScript 文件。
2. 将下面的 JavaScript 代码复制并粘贴到 app.js 中。

```javascript
document.addEventListener("DOMContentLoaded", initializeApp);

function initializeApp() {
  const loadFileButton = document.getElementById("loadFileButton");
  const outputText = document.getElementById("outputText");

  loadFileButton.addEventListener("click", () =>
    fetchAndTransformFile(outputText)
  );
}

async function fetchAndTransformFile(outputElement) {
  clearOutput(outputElement);

  try {
    const response = await fetch("textfile.txt");
    const readableStream = response.body;
    const transformStream = createTransformStream();
    const writableStream = createWritableStream(outputElement);

    await readableStream.pipeThrough(transformStream).pipeTo(writableStream);

    console.log("File stream processing completed");
  } catch (error) {
    handleError(error, outputElement);
  }
}

function createTransformStream() {
  return new TransformStream({
    transform(chunk, controller) {
      const text = new TextDecoder().decode(chunk);
      const upperCaseChunk = text.toUpperCase();
      controller.enqueue(new TextEncoder().encode(upperCaseChunk));
    },
  });
}

function createWritableStream(outputElement) {
  return new WritableStream({
    write(chunk) {
      const text = new TextDecoder().decode(chunk);
      outputElement.textContent += text;
    },
  });
}

function clearOutput(outputElement) {
  outputElement.textContent = "";
  outputElement.style.color = "black";
}

function handleError(error, outputElement) {
  console.error("Error during stream processing:", error);
  outputElement.textContent = `An error occurred: ${error.message}`;
  outputElement.style.color = "red";
}
```

3. 保存并退出文件。
4. 允许传入连接到端口 8080。
5. 启动文件服务器。
6. 访问应用程序 URL `http://<server-ip>:8080`，然后点击 **“加载和转换”** 按钮。您将看到整个文本文件被提取并转换为大写字符。

点击 **“加载和转换”** 按钮后，该`fetchAndTransformFile()`函数将从`textfile.txt`服务器的文件系统中获取数据。服务器以 的形式响应数据`ReadableStream`，这使得文件可以分块处理。在客户端，这些数据`ReadableStream`通过 进行管道传输，该`TransformStream`函数将每段文本转换为大写。转换后的文本块随后通过管道传输到`WritableStream`，该函数将结果文本附加到 HTML 元素中以供显示。这展示了如何使用 Streams API 获取文件，并在获取数据时在浏览器中处理、转换和显示数据，而不是在内存中对整个文件执行操作。

## 真实世界的用例和示例

**1. 在视频流媒体平台**

- 用例：高效处理和传送大型视频文件。
- 示例：视频流服务可以使用 Streams API 将大型视频文件分解成较小的块，进行处理（例如，应用滤镜或压缩），然后逐步将其交付给用户。这可以实现更流畅的播放并减少初始加载时间。

**2. 在数据可视化应用中**

- 用例：用于大型数据集或连续数据流的实时处理和可视化。
- 示例：财务仪表板可以使用 Streams API 实时处理市场数据。新数据到达后，可以进行转换、过滤，并立即显示在图表或图形上，从而实现实时更新，且不会占用过多的浏览器资源。

**3. 在文件上传/下载系统中**

- 用例：用于处理具有进度跟踪和动态处理的大型文件传输。
- 示例：云存储服务可以使用 Streams API 上传大型文件。文件可以以流的形式读取，即时压缩或加密，然后分块发送到服务器。这允许跟踪传输进度、暂停和恢复传输，并高效利用内存，尤其是在处理超大文件时。
