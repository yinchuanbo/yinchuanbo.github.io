TypeScript 是由微软开发的开源编程语言，它是 JavaScript 的超集，添加了静态类型定义。TypeScript 代码会被编译成纯 JavaScript 代码，可以在任何支持 JavaScript 的环境中运行。

## 什么是 TypeScript

TypeScript = JavaScript + 静态类型 + 强大的开发工具支持

### 主要特性
- **静态类型检查**：在编译时发现错误
- **现代 JavaScript 特性**：支持 ES6+ 语法
- **强大的 IDE 支持**：智能提示、重构等
- **渐进式采用**：可以逐步迁移现有 JavaScript 项目

## 环境搭建

### 全局安装 TypeScript
```bash
# 使用 npm 安装
npm install -g typescript

# 使用 yarn 安装
yarn global add typescript

# 验证安装
tsc --version
```

### 项目初始化
```bash
# 创建项目目录
mkdir my-typescript-project
cd my-typescript-project

# 初始化 package.json
npm init -y

# 安装 TypeScript 作为开发依赖
npm install -D typescript @types/node

# 创建 TypeScript 配置文件
tsc --init
```

## 第一个 TypeScript 程序

### 创建 hello.ts 文件
```typescript
// hello.ts
function greet(name: string): string {
    return `Hello, ${name}!`;
}

const userName: string = "TypeScript";
console.log(greet(userName));
```

### 编译和运行
```bash
# 编译 TypeScript 文件
tsc hello.ts

# 运行生成的 JavaScript 文件
node hello.js
```

## TypeScript 配置文件 (tsconfig.json)

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "commonjs",
    "outDir": "./dist",
    "rootDir": "./src",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true
  },
  "include": ["src/**/*"],
  "exclude": ["node_modules", "dist"]
}
```

### 重要配置选项说明
- `target`: 编译目标 JavaScript 版本
- `module`: 模块系统类型
- `outDir`: 编译输出目录
- `rootDir`: 源文件根目录
- `strict`: 启用所有严格类型检查选项

## 实例演示：简单的计算器

```typescript
// calculator.ts
class Calculator {
    add(a: number, b: number): number {
        return a + b;
    }
    
    subtract(a: number, b: number): number {
        return a - b;
    }
    
    multiply(a: number, b: number): number {
        return a * b;
    }
    
    divide(a: number, b: number): number {
        if (b === 0) {
            throw new Error("Division by zero is not allowed");
        }
        return a / b;
    }
}

const calc = new Calculator();
console.log(calc.add(10, 5));      // 15
console.log(calc.subtract(10, 5)); // 5
console.log(calc.multiply(10, 5));  // 50
console.log(calc.divide(10, 5));    // 2
```

这个例子展示了 TypeScript 的基本语法，包括类定义、方法参数类型注解、返回值类型注解等。
